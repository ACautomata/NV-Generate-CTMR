# L2 合成域适用性评估:P3 img2img 零训练基线(4 锚轮协议)

**总体判定**: **PASS**|**记录落盘日**: 2026-08-29|**实际运行窗口**: 2026-08-20 16:18–19:54(+0800, sugon 集群,单日完成)

## 1. 目的与关联 issue

在 v1 DM img2img 零训练基线产物上测 L2 冻结测量仪器的输入契约失败率与层级违反率,建立合成域适用性前置证据(零循环、不依赖任何微调产物;与 P1 的独立采样直出不同,P3 样本为真实锚 + img2img 生成通道,见 #38)——依据 [#32](https://github.com/ACautomata/NV-Generate-CTMR/issues/32) resolution §5「合成域适用性」,执行与判定见 [#38](https://github.com/ACautomata/NV-Generate-CTMR/issues/38)(已关票,判定 PASS),记录落盘见 #186(父 spec)。本记录是已出清文件 `eval/l2-synth-domain/report_p3.md` 的正式转写(出清于 b8759e7 / #145,原路径不恢复),转写任务见 #194。

## 2. 运行配置与 run_id

- **生成模型**: v1 DM `diff_unet_3d_rflow-mr-brain_v1.pt`(零训练基线,无 ControlNet),官方推理配置(30 步、cfg=2、256×256×128 @ 0.94×0.94×1.36mm;img2img 为 RF 插值 **strength=0.9,截断后 25 步**)。
- **采样协议(P3 式,4 锚轮协议)**: 88 病例(GLI/MEN/METS/PED/SSA = 20/20/20/14/14,dev 优先)× 4 锚轮——每轮一个真实模态作锚(dev 病例取 dev_raw 原始、fold_val 病例取 nnU-Net imagesTr),其余三模态以该锚为 src img2img 生成,12 有序模态对全覆盖;每体 = 1 真实锚通道 + 3 生成通道,共 352 体;seed = 全表位置×10000 + 锚标签×100 + 目标标签;8 GPU 分片断点续跑(`make_p3_jobs.py` + `p3_launch_shards.sh`,约 1.5h)。
- **仪器**: ADR-0003 冻结件(自训 MONAI nnU-Net,nnUNetTrainer250Epochs fold_0,SSA 派生 plans `nnUNetPlans_SSA_bs16_v1/3d_fullres_bs16`);输入经 1mm 重采样 + 240×240×155 对齐(真实锚通道直接用原始数据重采样对齐);R_fail 三分(input_fail | run_fail | hier_viol)与 #36 校准一致。
- **评估链**: `run_eval.py --mode p3`(sugon 自包含脚本)→ 冻结仪器 predict → 逐病例 R_fail 分解 + Wilson 95% 上界。
- **run_id**: 无云端 run_id(sugon 自包含产物,以产物目录为身份);仪器校准 run 锚 `252940d0156f4c1258936fa25a1fb28bad61ae22`。
- **底稿互核**: git 历史锚点(`git show b8759e7^:eval/l2-synth-domain/report_p3.md`)与服务器原件 `/root/private_data/l2-synth-eval/report_p3/`(.md/.json)逐项一致,**无差异需注明**;case_results.json 分母(GLI/MEN/METS 各 80、PED/SSA 各 56)与主表样本数一致(20/14 病例 × 4 锚轮)。

## 4. 结论与后续动作

**结论: 合成域适用性成立(PASS)。** 五挑战 R_fail_synth 全 0(0/80×3、0/56×2),细分 input_fail/run_fail/hier_viol 全 0,无 undecided 触发;判定与已关票的 #38 resolution 一致,与 CLOSED 状态无偏差。

方向说明(P3): P3 为 img2img 零训练基线(RF 插值 strength=0.9,无 ControlNet):每轮一个真实模态作锚、其余三模态以该锚为 src 生成,12 有序模态对全覆盖;真实锚通道直接用原始数据(重采样对齐),生成通道为 v1 DM img2img 输出。跨模态自洽性强于 P1 但弱于待训 P3 ControlNet,仅作合成域适用性前置证据。

后续动作:
