## 3. 关键发现

### RC-1 z-crop 测量轴——体积正偏本地排除

生成 grid 256×256×128 @ 0.94×0.94×1.36 mm，1mm 重采样后 241×241×174，居中裁到 240×240×155 砍 19 个 z 层（≈11%，仅生成侧；真实侧原生 155 不裁）。

- 体积方向： 裁剪只会**低估**生成侧 WT 体积 → `vol_wt_rel` 正偏被保守化，真实的正偏只会更大。z-crop **不能**解释体积正偏。
- 质心 x/y： x/y 裁剪量仅 0.5 voxel，可忽略；x/y 质心 CI 宽且近对称（如 GLI x [-44.6, 43.2]）是真实的「肿瘤放置低精度/重尾」，无裁剪故事。
- 质心 z： 唯一可能有 z-crop 贡献的量（叠加「DM 训练数据 z 向 pad 对齐方式未单独验证」，P1 L2 终验记录原话），留服务器作业 A 定量。

### RC-2 modality token 增广——ET 缺失机制坐实

`ModalityLabelPerturber`（`src/ctmr/domain/generation/objective.py:87-97`，`PINNED_PROB=0.1`）逐元素独立 Bernoulli。对每个 t1c 训练步：P(保留 34)=0.81，P(→8 泛 MR)=0.09，P(→0 unknown)=0.10——**≈19% 的 t1c 步在教模型「34 无特异语义」**。token 经 class_labels 路径注入（`model.py:108`，`config_network_rflow.json:62` `num_class_embeds=128` 查表 embedding）；token 34 是唯一承载「强化对比外观」语义的 token（ET 的唯一条件线索）。推理 CFG=10 放大 (cond−uncond) 差，cond 被稀释即有效引导减弱。

- 对 ET 缺失： 方向明确、机制可靠，量级 ≤19% 步数。
- 对 WT 偏大： 解释力弱（削的是模态特异度，不指向体积）。

### RC-3 1:1 replay 与 token 语义错位

- 混合层级： 两 list 拼接 + 硬断言 1:1（`modality_label/train.py:83-92`）+ 全局 shuffle，≈50/50 逐步抽签；replay 用 token 9/10/11（whole-brain T1/T2/FLAIR，ADR-0005 决定 1-2），不是 34。
- **P1 不加载任何分割 label、不用 weighted_loss**（`train.py:163-172,238-242`；损失为 plain RF 速度场 L1，`model.py:109-112`）——「replay 病例 label 权重」问题不存在。
- **token 语义错位（新事实）**： 底座 v1 的 token 29/30/31（skull-stripped）语义学自 MR-RATE 去颅骨半（`data/README.md` §3.4）；P1 回放只含 whole-brain（9/10/11），故 **29/30/31/34 在 P1 中只收 BraTS 带瘤梯度**——四个 token 的语义被整体拉向「带瘤脑先验」；增广 34→8 又桥接两个 token 族互渗。
- 候选选择只按 dev FID（ADR-0005 决定 5），对 WT/ET 体积偏差全盲。

### RC-4 t1c 预处理与评估盲区

训练侧编码管线（`create_training_data.py`，vendored，服务器 launcher 已退役、git 历史还原）： 归一化 → resize（`ScaleIntensityRangePercentilesd(0, 99.5 → 0, 1, clip=False)`，`instance_definition.py:57-59`； BraTS 240×240×155 → 256×256×128，z 向 155→128 为 trilinear 下采样，全链无 padding）→ VAE encode（fp32 latent 落盘，无量化）。

- **直接嫌疑证伪**： `clip=False` 使 ET 亮核（全卷最顶 ~0.5% 体素）**不被截断**，而是线性外推到 >1.0——「预处理把亮核 clip 掉」不成立。
- **变体机制成立待验**： 外推的 >1.0 输入是否在冻结 autoencoder_v1 的训练分布内**未证实**（见 §4 纠偏）；叠加 z 向 155→128 压缩对薄壁环形强化的体素平均模糊，VAE encode→decode 对 ET 对比度的保真度是全链唯一缺失的实测环节（仓库内仅有退役原型 `prototype/vae_recon_brats/` 开篇的疑问痕迹，无存档结论）。
- **评估盲区（回答「为什么 PSNR/SSIM 看不见这病」）**： 评估归一化 `MRIntensityNormalizer`（`intensity_protocol.py:31-41`）为 `clip=True`，把两侧 top 0.5% 一并压到 1.0——ET 缺口在 PSNR/SSIM 上**结构性不可见**；L2 分割仪器是唯一看得见 ET 的读数，而它判了 FAIL。P1 生成输出侧 `synthetic * 1000 → int16` 只下截不上截（`modality_label/monitor.py:161-163`），>1.0 输出会写成 >1000。
- 评估协议四处错位（存档备考）： ① clip 方向相反（训练 clip=False vs 评估 clip=True）；② 归一化与 resize 次序颠倒（训练 normalize→resize，评估 resize→normalize）；③ 「0–99.5 percentile」三种实现并存且分位基底不一（`trend.py:103-110` FID real bank 用非零体素，编码与 `MRIntensityNormalizer` 用全体素）；④ 训练 z 压缩几何（155→128，spacing ≈1.21 mm）与仪器链 1mm 重采样（`grid.py:87` `INSTRUMENT_GRID=(240,240,155)`）不同。
- 对照线索： P1/P2/P3 训练 embedding 同批同源（同一次 encode 运行的同一批 `_emb.nii.gz`）；P3 推理时锚编码（`cross_modal/anchor.py:42-51`）逐字复刻训练编码协议。

## 4. 用户纠偏：VAE 训练数据含 T1c

用户目检纠偏并自验：**VAE（autoencoder_v1）训练数据包含 T1c**。核对结果：

- `data/README.md` §2.1： VAE MRI 训练数据含 **TCIA Upenn GBM Brain MR（skull-stripped）** 等脑 MR 采集（README 按数据集列出、未列对比度级明细）；GBM 采集通常含增强后 T1，与用户自验一致，**采纳该纠偏**。
- 本会话对 MAISI 论文（arXiv 2409.11169）的检索未提取到对比度级 VAE 训练明细，论文级核对未完成，以用户自验 + README §2.1 佐证入档。
- **对根因链的影响**： 「VAE 从未见过 T1c/增强肿瘤」的说法**不成立**，撤销；开放问题收窄为——VAE 训练时的归一化约定（clip 与否）是否使 clip=False 外推的 >1.0 输入位于其训练分布内。此问题**只能实证**（服务器作业 C），不再作纸面推断。
- **不受影响的结论**： 「token 34 语义真空」是 **DM 底座**侧事实（§3.4 MR-RATE 五模态无 t1c），与 VAE 纠偏分属两个组件，维持。
