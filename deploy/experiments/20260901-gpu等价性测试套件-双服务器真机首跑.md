## 修复的真机缺陷(→ bdf842a)

1. **`set_device(torch.device("cuda"))` 无 index → ValueError**(`Expected a torch.device with a specified index or an integer`)——#298/#301 先例 worker 代码潜在 bug,真机首跑暴露。
2. **nccl 臂 env:// 固定 TCP rendezvous 在共享服务器无安全口**:bind(0) 探测与 rank0 listen 间隔数秒 spawn 窗口,ephemeral 段被连接 churn 抢占、295xx 段与 torchrun 默认 master 口(29500)互撞,EADDRINUSE 7/7 → 三文件统一改 **file:// FileStore rendezvous**(单机共享盘按 model_dir 隔离;NCCL/RCCL 自身通信口由内核临时分配,不受影响),`_free_port` 删除。
3. **worker 内 per-rank `CUDA_VISIBLE_DEVICES` 覆写在 HIP/DCU 栈无效**(HIP 全局 ID 为 36000 系而非序数,解析失败回退全可见),双 rank 落同一张卡 → RCCL `Duplicate GPU detected` 中止 → 改 torchrun local_rank 惯例 `set_device(rank)`;选卡交给调用方父进程 mask(NVIDIA 用 `CUDA_VISIBLE_DEVICES`;DCU 上 `CUDA_VISIBLE_DEVICES` 与 `HIP_VISIBLE_DEVICES` 父进程侧均验有效)。
